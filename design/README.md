# design 目录说明

本目录保存 Gate 1 的设计与排版资产：资讯卡片展示字段定义、设计系统与 Web 原型、公众号排版模板及其导出物。本目录不放代码实现、采集脚本、依赖配置或凭据。

## 文件清单

| 文件 | 用途 |
|---|---|
| `card-fields-v0.md` | 资讯卡片展示字段定义 v0（LD-G1-01）；仅供 UI 与排版原型使用，不是 Gate 2 的正式采集数据契约（D-005） |
| `card-fields-v0.example.json` | 字段表对应的占位示例，共 5 条，覆盖五类标签；全部为虚构占位内容，不得作为事实引用 |
