## 一、设计理念与视觉哲学

LexAIDaily 面向执业律师、企业法务、合规官、法律科技从业者与司法研究者。v2.1 设计系统确立以下核心视觉与空间哲学：

1. **雾霭蓝灰 × 晨光亚麻 × 柔光白（底色体系）**：
   - 底层由雾霭蓝灰（`#A0BCCE`）向晨光亚麻（`#EAE1D3`）及暖白光晕（`#F8F4ED`）形成自然对角柔和过渡，衬托淡雅矢量水墨晕染背板，彻底摒弃冷硬暗黑或刺眼高亮，营造沉稳、书卷气且具现代科技感的专业研报基底。
2. **极简实色卡片（Strictly Solid Cards）**：
   - 依照 Human 决策 D-019，**资讯卡片一律采用实色卡片，杜绝滥用玻璃**。卡片选用高显色暖白（`#FFFDF8`），搭配 1px 微妙暖灰描边（`#E6DFC8`）与微弱柔和阴影（`0 4px 16px rgba(31, 27, 22, 0.06)`），确保长时间专业阅读的舒适性与极致文字清晰度。
3. **单一深海军蓝强调色（Single Accent Color）**：
   - 全站严格只允许 **1 个强调色** —— **深海军蓝**（`#14284B`，悬停态 `#0F2347`）。用于“头条”徽标实底、未核实标识外边框、选中项滑块、链接悬停等。杜绝多色系五彩斑斓的视觉干扰。
4. **悬浮液态玻璃导航（Liquid Glass Navigation）**：
   - 玻璃材质**严格限定仅用于两处**：① 底部居中悬浮的分类切换条；② 移动端顶部固定的日期导航栏。在原型中采用 82% 不透明度（`rgba(255, 255, 255, 0.82)`）配合条下 48px 渐隐遮罩；CSS 实装采用 64% 半透明配合 `backdrop-filter: blur(24px)`。
5. **错落瀑布流（Masonry Flow）**：
   - 桌面端采用 6 列栅格错落排布，卡片高度由内容自然决定，行不对齐，杜绝大面积空白；移动端采用双列错落排布布局，第一列顶部为“今日综述”卡片，第二列顶部为“关键词雷达”卡片，下方承接紧凑错落卡片。
6. **Ian’s Daily 3 分钟极速扫读节奏**：
   - 资讯列表卡片仅保留四要素核心信息（来源行 → 标题 → 摘要 → 一手信源直达），**列表卡片杜绝实务影响框**；实务影响深度分析后置于详情跳板页，强制附带 `[AI 初稿]` 标识。

### 2.4 状态徽标与标识规范

依“不得仅靠单一颜色区分状态”的无障碍设计原则，徽标体系通过形态、填充与轮廓严格区分：

1. **头条徽标（Headline Badge）**：
   - 视觉样式：深海军蓝实底（`#14284B`），纯白粗体文字（`#FFFFFF`），字号 `12px`，内边距 `2px 8px`，圆角 `6px`。
2. **未核实标识（Unverified Badge）**：
   - 视觉样式：深海军蓝细线边框（`1px #14284B`），背景完全透明，文字为深海军蓝（`#14284B`），字号 `12px` 粗体，严格禁用任何 emoji 图标。
3. **AI 初稿标识（Draft Badge）**：
   - 视觉样式：暖灰浅色边框（`1px #E6DFC8`），背景透明，文字为次要墨灰（`#6B6354`），字号 `12px` 粗体。
4. **分类标签（Category Tag）**：
   - 视觉样式：纯文字展示（`#6B6354`），无任何填充底色与轮廓描边，与状态徽标形成明确视差。

### 2.5 无障碍对比度计算脚本与回退验证

```python
# WCAG 2.1 相对亮度与对比度严格核算脚本
def L(h):
    h = h.lstrip('#')
    r = [int(h[i:i+2], 16) / 255 for i in (0, 2, 4)]
    f = lambda c: c / 12.92 if c <= 0.03928 else ((c + 0.055) / 1.055) ** 2.4
    r = [f(c) for c in r]
    return 0.2126 * r[0] + 0.7152 * r[1] + 0.0722 * r[2]

def C(a, b):
    x, y = sorted([L(a), L(b)], reverse=True)
    return round((x + 0.05) / (y + 0.05), 2)

# 核心色对实算
assert C("#1F1B16", "#FFFDF8") == 16.84  # Primary text (AAA)
assert C("#5C5549", "#FFFDF8") == 7.25   # Secondary text (AAA)
assert C("#6B6354", "#FFFDF8") == 5.84   # Muted text on card (AA)
assert C("#6B6354", "#F6F1E6") == 5.27   # Muted text on well (AA)
assert C("#FFFFFF", "#14284B") == 14.64  # White on Navy (AAA)
assert C("#14284B", "#A0BCCE") == 7.37   # Navy on Canvas (AA)
```

- **无障碍回退（Reduced-Transparency 令牌）**：
  在系统开启“降低透明度”或不支持 CSS `backdrop-filter` 的终端环境下，玻璃组件自动降级为实色 `#F6F1E6` 与 1px `#DCD4C0` 实线边框；激活滑块保持深海军蓝 `#14284B` 配白字 `#FFFFFF`（14.64:1），彻底杜绝白底白字（1.0:1）的不可见缺陷。

### 3.1 品牌字标排版架构（Brand Lockup）

依据 Human Maintainer 决策（[PR #16 评论 6842596303](https://github.com/fitalex/LexAIDaily/pull/16#issuecomment-6842596303)），品牌标识采用纯字标等宽对齐社媒矩阵架构：
- **桌面端站名**：思源宋体 `32px` Bold，强调色 `#14284B`，字距 `1.0px`，Penpot 实测宽度为 **206px**。站名字号控制在 32px，确保不压过头条标题（30px）。
- **桌面端 Slogan**：思源黑体 `18px` Medium，墨黑 `#1F1B16`，字距 `2.0px`，Penpot 实测宽度为 **206px**。
- **排版对齐**：站名与 Slogan 上下等宽（均为 206px），两端严格齐平下方 206px 社媒与日期矩阵，行间距设为 14px。
- **移动端站名**：思源宋体 `20px` Bold，强调色 `#14284B`，纳入 `brand.lockup.mobileWordmark` 令牌管理。
- **令牌管理**：全套参数收录于 `tokens.json` 的 `brand.lockup` 组，明确标注“按 206px 宽度反算，字体渲染变化时重算”。

## 四、卡片组件规范（三档尺寸与排布）

### 4.1 卡片规格与触发条件

大盘主信息流采用 6 列栅格网格（列间距统一为 `16px`，对应令牌 `layout.desktop.gutter`），错落排布，**行不对齐**，高度由内容自然决定，杜绝大面积空白：

| 尺寸档位 | 栅格列宽 | 标题字阶 / 行高 | 摘要上限 | 触发条件与排版特征 |
|---|---|---|---|---|
| **L（头条卡）** | 4 列 | 30px / 38px | 最多 6 行 | 仅当 `importance = 头条`，附带深海军蓝“头条”徽标，首部核心吸睛。 |
| **M（常规卡）** | 2 列 | 21px / 30px | 最多 4 行 | 摘要长度 ≥ 100 字时选用，提供详实背景信息。 |
| **S（简讯卡）** | 2 列 | 18px / 26px | 最多 2 行 | 摘要长度 < 100 字时选用，紧凑小巧，用于动态快讯。 |

### 4.2 卡片内容层级与间距预算

列表卡片严格控制为 4 层文字样式，杜绝过度修饰：
1. **来源行**：分类 · 事实层级（已证实事实/官方数据/市场观点）· 来源域名 · 日期（12.5px–13px 思源黑体，次要墨灰 `#6B6354`，严格 ≥ 12.5px）。
2. **核心标题**：18–32 字主标题（霞鹜文楷，墨黑 `#1F1B16`）。
3. **事实摘要**：精炼事实描述（15px / 行高 26px 思源黑体，次要墨灰 `#5C5549`，严格 ≥ 14.5px）。
4. **一手信源直达**：固定在摘要下方 **16px** 处（对应令牌 `component.card.linkGap`），卡片高度自适应内容包裹，彻底杜绝同行卡片拉伸导致的底部 100px 空白。

> **严格禁令**：**列表卡片严禁出现实务影响框**。实务影响内容一律收敛于详情跳板页。

## 五、导航组件与布局规范

### 5.1 悬浮分类切换条（Floating Glass Category Bar）

- **视口位置**：页面底部水平居中悬浮（`fixed bottom`）。
- **规格尺寸**：
  - **桌面端**：高度 **72px**（严格落在 8px 网格，令牌 `layout.desktop.catBarHeight`），最小宽度 **840px**，圆角 20px。
  - **移动端**：高度 **56px**（触控热区 ≥ 44px），圆角 9999px 胶囊形态。
- **光学与视觉**：
  - 原型玻璃不透明度 82%，条下设置 48px 渐隐遮罩；未选项目为 `#6B6354`（14px）；激活项为深海军蓝（`#14284B`）胶囊滑块配白字（15px/16px 粗体）。
  - 大盘（画板 01）条目计数与当日收录条数严格一致：全部 (5)、监管与合规 (2)、司法与判例 (1)、模型与技术 (1)、实务与工具 (1)、行业与资本 (1)。

### 5.2 日期导航与归档流

- **桌面端**：左侧设立独立极简流式日期面板（宽 240px），无厚重灰色底框，当前日期（`11月11日`）以深海军蓝高亮呈现（7.37:1），未选日期与“更多”采用墨黑 `#1F1B16`（8.62:1），禁止低对比度浅灰。
- **移动端**：顶部固定液态玻璃日期横滚条（高度 **52px**），内容向上滚动时在玻璃下方产生模糊渐隐。

### 5.3 移动端小红书双列瀑布流与字号红线

- 移动端视口（390 × 960 px）双列错落排布：
  - **事实摘要**：**严格 ≥ 14.5px（实测 15px / 22px）**，卡片宽度受限时减少行数，绝对不压缩字号。
  - **来源行与元数据**：**严格 ≥ 12.5px（实测 12.5px–13px）**。
  - **状态徽标**：**严格 12px 粗体**。
  - **标题**：**17px–18px** 霞鹜文楷。

## 六、详情跳板页与实务影响（Detail Jump Page）

详情跳板页（画板 03 桌面端、画板 07 移动端）是读者查验溯源与实务研判的核心中继站：

1. **正文阅读排版预算**：
   - 桌面端详情页正文栏宽上限设定为 **680px**（对应令牌 `layout.desktop.detailMeasure`，单行约 40 个中文字符，16px/28px 排版预算），彻底解决原 1050px 超宽行难读问题。

### 7.2 Canvas UI 效果槽位说明
