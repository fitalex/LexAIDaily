## 一、设计理念与视觉哲学

LexAIDaily 面向执业律师、企业法务、合规官、法律科技从业者与司法研究者。v2.0 设计系统确立以下核心视觉与空间哲学：

1. **雾霭蓝灰 × 晨光亚麻 × 深海军蓝**：
   - 底层由雾霭蓝灰（`#A0BCCE`）向晨光亚麻（`#EAE1D3`）及暖白光晕（`#F8F4ED`）形成自然对角柔和过渡，衬托淡雅水墨晕染背板，彻底摒弃冷硬暗黑或刺眼高亮，营造沉稳、书卷气且具现代科技感的专业研报基底。
2. **极简实色卡片（Strictly Solid Cards）**：
   - 依照 Human 决策 D-019，**资讯卡片一律采用实色卡片，杜绝滥用玻璃**。卡片选用高显色暖白（`#FFFDF8`），搭配 1px 微妙暖灰描边（`#E6DFC8`）与微弱柔和阴影，确保长时间专业阅读的舒适性与极致文字清晰度。
3. **单一深海军蓝强调色（Single Accent Color）**：
   - 全站严格只允许 **1 个强调色** —— **深海军蓝**（`#14284B`）。用于“头条”徽标、选中项滑块、未核实警示线、链接交互等。杜绝多色系五彩斑斓的视觉干扰。
4. **悬浮液态玻璃导航（Liquid Glass Navigation）**：
   - 玻璃材质**严格限定仅用于分类切换条**；日期导航采用白色实底胶囊（`#FFFDF8`，100% 实底），直接置于雾霭蓝灰底（`#A0BCCE`）之上。分类切换条提供半透明磨砂折射与高光微质感，浮于内容之上，不喧宾夺主。
5. **小红书双列瀑布流（Dual-Column Masonry Flow）**：
   - 移动端采用双列错落排布布局，第一列顶部为“今日综述”卡片，第二列顶部为“关键词雷达”卡片，下方承接紧凑错落卡片，兼顾移动端视觉探索感与高信息密度。
6. **Ian’s Daily 3 分钟极速扫读节奏**：
   - 资讯列表卡片仅保留四要素核心信息（来源行 → 标题 → 摘要 → 一手信源直达），**列表卡片杜绝实务影响框**；实务影响深度分析后置于详情跳板页，强制附带 `[AI 初稿]` 标识。

### 2.4 单一强调色与状态标识

- **深海军蓝（权威强调色）**：`#14284B`（悬停态 `#0F2347`）。
- **头条标记（Headline Badge）**：`#14284B` 深海军蓝实底，白字 `11px` 思源黑体，圆角 4px。
- **AI 初稿标识（Draft Badge）**：文字 `#6B6354`，边框 `1px #E6DFC8`，背景透明或纯白，小号无衬线文字，贴于摘要或实务影响旁。
- **未核实标识（Unverified Badge）**：文字 `#14284B`，外框 `1px #14284B` 细边，无填充，严格禁用 emoji 图标。
- **分类标签（Category Tag）**：纯文字无底色无描边，颜色 `#6B6354`，12.5px 思源黑体，位于来源行首。

### 2.5 可读性与无障碍对比度核算

- **红线标准**：正文与关键元数据对比度严格满足 WCAG 2.1 AA 级（≥ 4.5:1，大字 ≥ 3.0:1）；悬浮液态玻璃上的文字在最差背景折射下对比度必须 ≥ 4.5:1（DoD D03 与任务书 3.3）。
- **核算实测与证据**：
  - **白字与深海军蓝**：激活态滑块采用 `#14284B` 深海军蓝实底配 `#FFFFFF` 白字，对比度高达 **14.64:1**（AAA 级）。
  - **蓝灰底文字**：雾霭蓝灰底（`#A0BCCE`）直接承载的文字（如日期切换标签与“更多”链接）统一采用深海军蓝 `#14284B`（对比度 **7.37:1**，AAA 级）或墨黑 `#1F1B16`（对比度 **8.62:1**，AAA 级），杜绝在 `#A0BCCE` 上直接使用弱化色（`#6B6354` 仅 2.99:1）。
  - **卡片实底文字**：实色卡片（`#FFFDF8`）主标题墨黑 `#1F1B16` 对比度 **16.84:1**（AAA 级）；摘要正文 `#5C5549` 对比度 **7.25:1**（AAA 级）；来源域名与元数据采用 `#6B6354`，对比度达到 **5.84:1**（满足 AA 级要求，彻底解决旧版墨灰仅 3.68:1 不合规问题）。
  - **液态玻璃最差背景对比度与透出核算**：
    - **画板实测参数**：Penpot 原型分类条实测采用 **94%（0.94）** 不透明度白色填充（`rgba(255, 255, 255, 0.94)`）。
    - **物理混合底色**：94% 白色玻璃叠加底层折射最深文字色斑（墨黑 `#1F1B16`）后，物理混合底色亮度实测为 `rgb(242, 241, 241)`。
    - **文字对比度实测**：深海军蓝导航文字（`#14284B`）有效对比度达到 **12.98:1**（远超 AAA 级标准 7.0:1）；墨黑文字（`#1F1B16`）达到 **15.19:1**（AAA 级）；未激活次要分类文字（`#5C5549`）达到 **6.53:1**（AA 级）。
    - **透出反差控制**：底层墨黑文字在 94% 玻璃覆盖下的透出反差降至 **1.13:1**（显著优于 82% 时的 1.45:1 与 60% 时的 2.49:1；透出反差降至 1.13:1，淡影仍可辨，由渐变遮罩与版式进一步处理）。
    - **B2 批次目标值决策**：保持画板实测 **94%（0.94）** 不透明度作为最终基线，无需降至 82%（避免透出反差反弹）；B2 重点通过渐变遮罩进一步消除分类条顶部的视觉切断感。
- **无障碍回退（Reduced-Transparency）**：
  系统在 `design/tokens/tokens.json` 中配置了 `reducedTransparency` 纯色令牌组。在系统开启“降低透明度”或不支持 CSS `backdrop-filter` 的终端环境下，玻璃组件自动降级为实色 `#F6F1E6` 与 1px `#DCD4C0` 实线边框；滑块保持 `#14284B` 实底与 `#FFFFFF` 白字（14.64:1），保证清晰易读。
- **对比度与物理混合验算工具脚本**：
  ```python
  def L(h):
      r = [c / 255 for c in h] if isinstance(h, (tuple, list)) else [int(h.lstrip('#')[i:i+2], 16) / 255 for i in (0, 2, 4)]
      f = lambda c: c / 12.92 if c <= .03928 else ((c + .055) / 1.055) ** 2.4
      r = [f(c) for c in r]; return .2126 * r[0] + .7152 * r[1] + .0722 * r[2]
  def C(a, b):
      x, y = sorted([L(a), L(b)], reverse=True); return round((x + .05) / (y + .05), 2)
  def blend(fg, bg, alpha):
      f_rgb = [int(fg.lstrip('#')[i:i+2], 16) for i in (0, 2, 4)]
      b_rgb = [int(bg.lstrip('#')[i:i+2], 16) for i in (0, 2, 4)]
      return [round(alpha * f + (1 - alpha) * b) for f, b in zip(f_rgb, b_rgb)]

  # 纯色实底验算
  print("Ink Muted on Card:", C("#6B6354", "#FFFDF8"))       # 5.84:1 (AA)
  print("White on Slider:", C("#FFFFFF", "#14284B"))         # 14.64:1 (AAA)
  print("Navy on Slate Canvas:", C("#14284B", "#A0BCCE"))    # 7.37:1 (AAA)
  print("Primary on Slate Canvas:", C("#1F1B16", "#A0BCCE")) # 8.62:1 (AAA)

  # 玻璃最差背景物理混合实测（Penpot 94% 不透明度）
  blend_94 = blend("#FFFFFF", "#1F1B16", 0.94) # 94% 白色叠加最深墨黑底
  print("Navy on 94% Glass (worst-case):", C("#14284B", blend_94)) # 12.98:1 (AAA)
  print("Primary on 94% Glass (worst-case):", C("#1F1B16", blend_94)) # 15.19:1 (AAA)
  print("透出文字反差 (94% Glass):", C(blend_94, "#FFFFFF"))         # 1.13:1 (淡影仍可辨)
  ```

## 四、卡片组件规范（三档尺寸与排布）

### 4.1 卡片规格与触发条件

大盘主信息流采用 6 列栅格网格，错落瀑布流排布，**行不对齐**，高度由内容自然决定：

| 尺寸档位 | 栅格列宽 | 标题字阶 / 行高 | 摘要上限 | 触发条件与排版特征 |
|---|---|---|---|---|
| **L（头条卡）** | 4 列 | 30px / 38px | 最多 6 行 | 仅当 `importance = 头条`，附带深海军蓝“头条”徽标，左侧/首部核心吸睛。 |
| **M（常规卡）** | 2 列 | 21px / 30px | 最多 4 行 | 摘要长度 ≥ 100 字时选用，提供详实背景信息。 |
| **S（简讯卡）** | 2 列 | 18px / 26px | 最多 2 行 | 摘要长度 < 100 字时选用，紧凑小巧，用于动态快讯。 |

### 4.2 卡片内容层级与预算

列表卡片严格控制为 4 层文字样式，杜绝过度修饰：
1. **来源行**：分类 · 事实层级（已证实事实/官方数据/市场观点）· 来源域名 · 日期（12.5px 思源黑体，墨灰 `#6B6354`，对比度 5.84:1）。
2. **核心标题**：18–32 字主标题（霞鹜文楷，墨黑 `#1F1B16`）。
3. **事实摘要**：精炼事实描述（15px / 行高 26px 思源黑体，次要墨灰 `#5C5549`）。
4. **一手信源直达**：`example.com/source ↗`（下划线链接，悬停变深海军蓝）。一手信源链接固定于摘要正文下方 **16px**，摘要底部到链接留白严格 $\le 24\text{px}$（目标 16px）。卡片高度自适应包裹内容结束（底部留白 16px），杜绝固定撑高导致的大面积垂直空白。

> **严格禁令**：**列表卡片严禁出现实务影响框**。实务影响内容一律收敛于详情跳板页。

### 4.3 分类筛选与降级提示卡（Fallback Notice Card）

依据 Human 决策 D-021，桌面端原型展示 11 条（适配三列网格瀑布流大屏密度），移动端展示 6 条（适配双列紧凑流），两端条数差异纯属高保真设计阶段对不同视口排版密度的示例数据取舍，不构成产品规则。全量卡片均统一标注 `[示例]` 占位标记。

当用户在分类切换条中筛选特定分类（如“监管与合规”）时，页面仅展示属于该分类的既有卡片，并在列表末尾配置一张**《本日监管与合规更多候选条目核验说明》（合规降级提示卡）**：
- **文案风格**：平实、客观、严谨，杜绝夸张或感叹词。明确说明其余候选条目因暂无权威一手信源或处于非公开核验阶段，未纳入本日精选，提示读者切换“全部”或历史归档查看。
- **卡片样式**：与实色资讯卡片保持同规格圆角（16px）与边框（1px `#E6DFC8`），无过度修饰，提供通向采编准则的一手信源链接。

### 4.4 网格与间距约束（8px 空间网格）

- **桌面端**：同列内卡片垂直间距统一为 **16px**；3 列之间列间距统一为 **16px**；卡片紧凑包裹内容结束，底层留出 $\ge 90\text{px}$ 缓冲净空区，彻底杜绝文字或边框侵入底部悬浮分类条。
- **移动端**：双列网格列间距统一为 **16px**，左右外边距严格对称设为 **11px**（$390 = 11 + 176 + 16 + 176 + 11$）；同列内垂直卡片间距全量统一为 **16px**。

## 五、导航组件与布局规范

### 5.1 悬浮分类切换条（Floating Glass Category Bar）

- **视口位置**：页面底部水平居中悬浮（`fixed bottom`）。
- **规格尺寸**：
  - **桌面端**：高度 **74px**（严格 ≥ 64px），最小宽度 **840px**，内边距 8px 16px。
  - **移动端**：高度 **56px**（触控热区 ≥ 44px），横向流式滚动，两端渐隐遮罩。
- **文字与交互**：
  - 选项字号 **17px**（思源黑体中等字重）。
  - 未选项目为墨黑色（`#1F1B16`）；激活项为深海军蓝（`#14284B`）胶囊滑块配白字，或亮白高光玻璃滑块。
  - 包含“全部”与五大分类共 6 个选项，条目统计数（如 `12`）以 11px 小字呈现在文字右上角。

### 5.2 日期导航与归档流

- **桌面端**：左侧设立独立极简流式日期面板（宽 240px），无厚重灰色底框，当前日期（如 `11月11日`）以亮白圆角胶囊高亮呈现，下方排布往期日期流及条目计数（14px/15px 易读字阶）。
- **移动端**：顶部固定极简日期横滚条（高度 **52px**），采用白色实底胶囊（`#FFFDF8`，100% 实底），非激活日期直接置于雾霭蓝灰底（`#A0BCCE`）之上。

### 5.3 移动端小红书双列瀑布流

- 移动端视口（390 × 960 px）采用双列（2-column）错落排布：
  - **第一列顶部**：放置“今日综述”卡片（提炼今日全球核心风向与关键看点）。
  - **第二列顶部**：放置“本期关键词雷达”卡片（热度标签流，支持一键过滤）。
  - **下半部流式区**：两列交替排布 L/M/S 尺寸卡片，形成丰富自然的高级探索节奏。

## 六、详情跳板页与实务影响

详情跳板页（画板 03 桌面端、画板 07 移动端）是读者查验溯源与实务研判的核心中继站：

1. **核心标题与元数据**：全量展示资讯标题、原始发布机构、效力状态及发布时间。桌面端正文列宽度严格限制为 **680px 居中**（在 1132px 白色主卡内居中，正文字号 16px，行高 28px 思源黑体，单行约 40 字符），提供最佳长文扫读与合规审查舒适度。
2. **完整事实摘要**：客观交代事件全貌。
3. **实务影响深度研判（专属于此）**：
   - 包含法务行动建议、合规审查清单与业务风险提示。
   - **强制标识**：显著标明 `[AI 初稿]`（未获 Human 确认前必须保留）。
   - **紧凑包裹**：实务影响框与关联法规框高度严格贴合文本内容结束（如桌面端分别为 156px 与 123px，移动端分别为 132px 与 118px），杜绝大面积空白空洞。
   - **移动端间距**：移动端摘要点 3 到实务影响研判框间距调整为 **20px**（严格 $\ge 16\text{px}$）。
4. **一手信源直达跳转核心按键**：
   - 突出展示官方一手原文直达按键（如 `直达官方一手信源 ➔`），附带防钓鱼与免责声明，无一手链接严禁入选。
5. **左侧侧栏极简控制**：
   - 桌面端左侧仅保留“← 返回今日精选大盘”与“前往历史归档检索 ➔”两枚核心导航按键，彻底删除“单条溯源跳板模式”弹窗框体与查验人多余文字。
