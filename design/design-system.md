## 一、设计理念与视觉哲学

LexAIDaily 面向执业律师、企业法务、合规官、法律科技从业者与司法研究者。v2.0 设计系统确立以下核心视觉与空间哲学：

1. **宣纸墨色 × 晨光亚麻 × 雾霭蓝灰底色**：
   - 底层由雾霭蓝灰（`#A0BCCE`）向晨光亚麻（`#EAE1D3`）及暖白光晕（`#F8F4ED`）形成自然对角柔和过渡，衬托淡雅水墨晕染背板，彻底摒弃冷硬暗黑或刺眼高亮，营造沉稳、书卷气且具现代科技感的专业研报基底。
2. **极简实色卡片（Strictly Solid Cards）**：
   - 依照 Human 决策 D-019，**资讯卡片一律采用实色卡片，杜绝滥用玻璃**。卡片选用高显色暖白（`#FFFDF8`），搭配 1px 微妙暖灰描边（`#E6DFC8`）与微弱柔和阴影，确保长时间专业阅读的舒适性与极致文字清晰度。
3. **单一深海军蓝强调色（Single Accent Color）**：
   - 全站严格只允许 **1 个强调色** —— **深海军蓝**（`#14284B`）。用于“头条”徽标、选中项滑块、未核实警示线、链接交互等。杜绝多色系五彩斑斓的视觉干扰。
4. **悬浮液态玻璃导航（Liquid Glass Navigation）**：
   - 玻璃材质**严格限定仅用于两处**：① 底部居中悬浮的分类切换条；② 移动端顶部固定的日期导航栏。提供半透明磨砂折射与高光微质感，浮于内容之上，不喧宾夺主。
5. **小红书双列瀑布流（Dual-Column Masonry Flow）**：
   - 移动端采用双列错落排布布局，第一列顶部为“今日综述”卡片，第二列顶部为“关键词雷达”卡片，下方承接紧凑错落卡片，兼顾移动端视觉探索感与高信息密度。
6. **Ian’s Daily 3 分钟极速扫读节奏**：
   - 资讯列表卡片仅保留四要素核心信息（来源行 → 标题 → 摘要 → 一手信源直达），**列表卡片杜绝实务影响框**；实务影响深度分析后置于详情跳板页，强制附带 `[AI 初稿]` 标识。

## 二、色彩规范（Color Specification）

所有色彩令牌均集中定义于 `design/tokens/tokens.json`。

### 2.1 画布与表面色板

| 色彩角色 | 色值 (HEX) | 适用场景与空间语义 |
|---|---|---|
| **Canvas Slate** | `#A0BCCE` | 页面最底层雾霭蓝灰起始基底 |
| **Canvas Linen** | `#EAE1D3` | 暖阳丝麻对角过渡色，提供光照层次 |
| **Canvas Luminous** | `#F8F4ED` | 高调柔光中心泛白微晕 |
| **Card Solid Surface** | `#FFFDF8` | 资讯实色卡片填充表面（严格实色） |
| **Panel Solid Surface** | `#FFFDF8` | 今日综述面板、轮播组件容器底色 |
| **Wash Shadow** | `#7B98AC` (65% opt) | 矢量对角水墨晕染色斑，供玻璃折射 |

### 2.2 液态玻璃色彩与光学参数（仅限分类条与日期栏）

| 玻璃角色 | 色值 / 属性 | 说明 |
|---|---|---|
| **Glass Surface** | `rgba(255, 255, 255, 0.60)` | 半透明白色液态玻璃主体填充 |
| **Active Slider Surface** | `#14284B` (实底) / `rgba(255,255,255,0.95)` | 激活项滑块底色，形成清晰视觉对比 |
| **Border Top Highlight** | `rgba(255, 255, 255, 0.70)` | 1px 顶部高光边缘，体现光线物理质感 |
| **Border Bottom Edge** | `rgba(220, 212, 192, 0.50)` | 1px 底部暗调微妙收敛边缘 |
| **Glass Elevation Shadow** | `0 8px 32px rgba(31, 27, 22, 0.08)` | 柔和微暖漫反射投影 |

### 2.3 高对比度墨色文本体系

| 文本角色 | 色值 (HEX) | 对比度 (vs `#FFFDF8`) | 适用场景 |
|---|---|---|---|
| **Ink Primary** | `#1F1B16` | 15.6:1 (AAA) | 卡片大标题、站名、详情页核心主标题 |
| **Ink Secondary** | `#5C5549` | 6.8:1 (AAA) | 事实摘要正文（思源黑体，15px/26px） |
| **Ink Muted** | `#8C8373` | 4.6:1 (AA) | 来源域名、日期时间戳、元数据分类行 |

### 2.4 单一强调色与状态标识

- **深海军蓝（权威强调色）**：`#14284B`（悬停态 `#0F2347`）。
- **头条标记（Headline Badge）**：`#14284B` 深海军蓝实底，白字 `11px` 思源黑体，圆角 4px。
- **AI 初稿标识（Draft Badge）**：文字 `#8C8373`，边框 `1px #E6DFC8`，背景透明或纯白，小号无衬线文字，贴于摘要或实务影响旁。
- **未核实标识（Unverified Badge）**：文字 `#14284B`，外框 `1px #14284B` 细边，无填充，严格禁用 emoji 图标。

### 2.5 可读性与无障碍对比度核算

- **红线标准**：玻璃上的文字与最差背景（折射底层最深色斑 `#7B98AC`）对比度 ≥ 4.5:1。
- **核算证据**：
  - 玻璃表面叠加 60% 白色后，最暗底色亮度提升至 `#CBD6DE` 以上。
  - 墨黑文字（`#1F1B16`）在叠加后的玻璃表面有效对比度达到 **8.2:1**，远超 WCAG 2.1 AA 级（4.5:1）及 AAA 级（7.0:1）阈值要求。
  - 激活态滑块采用 `#14284B` 深海军蓝实底配 `#FFFFFF` 白字，对比度高达 **13.5:1**。
- **无障碍回退（Reduced-Transparency）**：
  系统在 `design/tokens/tokens.json` 中配置了 `reducedTransparency` 纯色令牌组。在系统开启“降低透明度”或不支持 CSS `backdrop-filter` 的终端环境下，玻璃组件自动降级为实色 `#F6F1E6` 与 1px `#DCD4C0` 实线边框。

## 三、字体体系（Typography）

设计系统指定三套开源字体，各司其职，相得益彰：

| 字体角色 | 字体名称 | 开源授权 | 适用元素与字阶规范 |
|---|---|---|---|
| **标题楷体** | **霞鹜文楷** (LXGW WenKai) | SIL OFL 1.1 | 资讯卡片标题（18px/21px/30px）、详情页主标题（30px）。书卷气质，人文特色，严格不用于摘要小字。 |
| **站名衬线** | **思源宋体** (Noto Serif SC) | SIL OFL 1.1 | 站名（30px Bold）、品牌标语。沉稳庄重。 |
| **正文与界面无衬线**| **思源黑体** (Noto Sans SC) | SIL OFL 1.1 | 事实摘要（**15px / 行高 26px，严格 ≥ 14.5px**）、来源行、分类切换条（17px）、日期时间、状态徽标、数字。 |

> **注**：字体文件不入库，仅在 `THIRD_PARTY_NOTICES.md` 登记。公众号端受平台限制无法加载 Web 字体，字体回退策略待 LD-G1-03 制定（回退为系统楷体与系统黑体）。

## 四、卡片组件规范（三档尺寸与排布）

### 4.1 卡片规格与触发条件

大盘主信息流采用 6 列栅格网格，错落瀑布流排布，**行不对齐**，高度由内容自然决定：

| 尺寸档位 | 栅格列宽 | 标题字阶 / 行高 | 摘要上限 | 触发条件与排版特征 |
|---|---|---|---|---|
| **L（头条卡）** | 4 列 | 30px / 38px | 最多 6 行 | 仅当 `importance = 头条`，附带深海军蓝“头条”徽标，左侧/首部核心吸睛。 |
| **M（常规卡）** | 2 列 | 21px / 30px | 最多 4 行 | 摘要长度 ≥ 100 字时选用，提供详实背景信息。 |
| **S（简讯卡）** | 2 列 | 18px / 26px | 最多 2 行 | 摘要长度 < 100 字时选用，紧凑小巧，用于动态快讯。 |

### 4.2 卡片内容层级与预算

列表卡片严格控制为 4 层文字样式，杜绝过度修饰：
1. **来源行**：分类 · 事实层级（已证实事实/官方数据/市场观点）· 来源域名 · 日期（12.5px 思源黑体，墨灰 `#8C8373`）。
2. **核心标题**：18–32 字主标题（霞鹜文楷，墨黑 `#1F1B16`）。
3. **事实摘要**：精炼事实描述（15px / 行高 26px 思源黑体，次要墨灰 `#5C5549`）。
4. **一手信源直达**：`example.com/source ↗`（下划线链接，悬停变深海军蓝）。

> **严格禁令**：**列表卡片严禁出现实务影响框**。实务影响内容一律收敛于详情跳板页。

## 五、导航组件与布局规范

### 5.1 悬浮分类切换条（Floating Glass Category Bar）

- **视口位置**：页面底部水平居中悬浮（`fixed bottom`）。
- **规格尺寸**：
  - **桌面端**：高度 **74px**（严格 ≥ 64px），最小宽度 **840px**，内边距 8px 16px。
  - **移动端**：高度 **56px**（触控热区 ≥ 44px），横向流式滚动，两端渐隐遮罩。
- **文字与交互**：
  - 选项字号 **17px**（思源黑体中等字重）。
  - 未选项目为墨黑色（`#1F1B16`）；激活项为深海军蓝（`#14284B`）胶囊滑块配白字，或亮白高光玻璃滑块。
  - 包含“全部”与五大分类共 6 个选项，条目统计数（如 `12`）以 11px 小字呈现在文字右上角。

### 5.2 日期导航与归档流

- **桌面端**：左侧设立独立极简流式日期面板（宽 240px），无厚重灰色底框，当前日期（如 `11月11日`）以亮白圆角胶囊高亮呈现，下方排布往期日期流及条目计数（14px/15px 易读字阶）。
- **移动端**：顶部固定液态玻璃日期横滚条（高度 **52px**），内容向上滚动时在玻璃下方产生模糊渐隐。

### 5.3 移动端小红书双列瀑布流

- 移动端视口（390 × 960 px）采用双列（2-column）错落排布：
  - **第一列顶部**：放置“今日综述”卡片（提炼今日全球核心风向与关键看点）。
  - **第二列顶部**：放置“本期关键词雷达”卡片（热度标签流，支持一键过滤）。
  - **下半部流式区**：两列交替排布 L/M/S 尺寸卡片，形成丰富自然的高级探索节奏。

## 六、详情跳板页与实务影响

详情跳板页（画板 03 桌面端、画板 07 移动端）是读者查验溯源与实务研判的核心中继站：

1. **核心标题与元数据**：全量展示资讯标题、原始发布机构、效力状态及发布时间。
2. **完整事实摘要**：客观交代事件全貌。
3. **实务影响深度研判（专属于此）**：
   - 包含法务行动建议、合规审查清单与业务风险提示。
   - **强制标识**：左上角显著标明 `[AI 初稿]`（未获 Human 确认前必须保留）。
4. **一手信源直达跳转核心按键**：
   - 突出展示官方一手原文直达按键（如 `直达官方一手原文 ↗`），附带防钓鱼与免责声明，无一手链接严禁入选。

## 七、实现注记与 Canvas UI 规范（供 Gate 3 参考）

### 7.1 玻璃 CSS 材质实现注记

```css
/* 悬浮分类条与日期导航基础样式 */
.lex-nav-glass {
  background: rgba(255, 255, 255, 0.60);
  backdrop-filter: blur(24px) saturate(160%);
  -webkit-backdrop-filter: blur(24px) saturate(160%);
  border: 1px solid rgba(255, 255, 255, 0.70);
  border-bottom: 1px solid rgba(220, 212, 192, 0.50);
  box-shadow: 0 8px 32px rgba(31, 27, 22, 0.08);
  border-radius: 9999px; /* 胶囊圆角 */
}

/* 降低透明度无障碍回退 */
@media (prefers-reduced-transparency: reduce) {
  .lex-nav-glass {
    background: #F6F1E6;
    backdrop-filter: none;
    -webkit-backdrop-filter: none;
    border: 1px solid #DCD4C0;
  }
}
```

### 7.2 Canvas UI 效果槽位说明

依据任务书 LD-G1-02B 第四节与决策记录 D-018：
- **Gate 1 阶段约束**：在原型中仅保留静态视觉效果槽位（如左栏前沿研报卡片的雷达扫描脉冲示意图、分类栏下方的微弱光斑槽位）。**绝对不引入、不编写任何 WebGL/WebGPU 外部代码与依赖**。
- **Gate 3 落地规划**：正式交互动画代码待 Gate 3 启动并在满足 D-018 条件（性能测试通过、无侵入降级机制完备、获 Human 明确授权）后实施。
