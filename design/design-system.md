## 一、设计理念与空间秩序

LexAIDaily 面向执业律师、企业法务、法律研究者、LegalTech 从业者与内容运营者。系统确立两大核心设计哲学：

1. **Canvas UI 空间秩序感**：采用深色冷调基底（`#090D16`）与精密发光雷达点阵构筑专业严肃的工具感，彻底抛弃浮夸冗余修饰，让信息结构成为界面骨架。
2. **Ian’s Daily 3 分钟极速扫读结构**：以严苛的视觉层级划分“核心标题（一眼扫读）→ 实务影响锚点（价值研判）→ 精炼事实摘要（背景印证）→ 原始信源跳板（查验溯源）”，单期内容保证读者在 3 分钟内完整把握全球法律 AI 关键动态。

- **未核实标识**：文字 `#FCA5A5`，底色 `#450A0A`，边框 `#991B1B`。固定文案“未核实 ⚠️”，提示发布机构、日期、版本或效力状态存疑。
- **事实层级三档**：
  1. `[已证实事实]`：绿色态（`#34D399` / `#064E3B`）；
  2. `[官方数据]`：中性钛灰态（`#CBD5E1` / `#1E293B`）；
  3. `[市场观点]`：焦橙态（`#FDBA74` / `#431407`）。

## 四、栅格与响应式布局（Grid & Breakpoints）

### 4.1 桌面端视图（Desktop Viewport: 1440px）

- **总宽**：1440px；**安全内容区**：1360px；**左右页边距**：40px。
- **双栏分流布局**：
  - **主信息流区（左侧）**：宽度 940px，容纳标准资讯卡片单列纵向排列，垂直间距 14–16px。
  - **辅助研判区（右侧）**：宽度 390px，容纳 3 分钟扫读指引、五大分类热度索引、双端协同提示。

### 4.2 移动端视图（Mobile Viewport: 390px）

- **总宽**：390px（iPhone 典型基准尺寸）；**左右页边距**：16px。
- **单栏流式布局**：卡片宽度自适应 358px。
- 顶部设横向滚动分类 Chip 条，移除右侧复杂侧栏，以保证极速扫读流畅性。

## 五、标准资讯单元（卡片组件规范）

本卡片规范严格转写 `design/card-fields-v0.md`，实现四要素与三大状态位的一致呈现：

```text
+----------------------------------------------------------------------------------+
| [五类分类标签]  [事实层级徽标]  [未核实标识(条件)]      发布机构 · 2026-11-11 · 时间戳   |
|                                                                                  |
| 核心标题：18–32 字高对比度主标题（桌面单行，移动端最多 2 行）                    |
|                                                                                  |
| 精炼事实摘要：2–3 句说清客观事实，严格区分事实与观点（字数 60–120 字，限 160 字） |
|                                                                                  |
| +------------------------------------------------------------------------------+ |
| | | [AI 初稿]  实务影响锚点：法务与合规行动清单及影响深度分析（30–60 字）       | |
| +------------------------------------------------------------------------------+ |
|                                                                                  |
| 一手信源：cac.gov.cn (官方通知公告) ↗                     [进入详情跳板 ➔]       |
+----------------------------------------------------------------------------------+
```

### 5.1 四要素排版预算与降级规则

1. **核心标题（必填）**：18–32 字为宜，硬上限 40 字。缺失时该卡片不展示并标待补。
2. **精炼摘要（必填）**：60–120 字为宜，上限 160 字。缺失时不以标题或锚点代替，卡片标待补。
3. **实务影响锚点（必填）**：30–60 字为宜，上限 80 字。左侧带发光色条（4px `#38BDF8`），背景 `#0B1528`，强制附带 `[AI 初稿]` 标识。缺失时卡片不展示并标待补。
4. **原始信源链接（必填）**：展示域名 + 短标识（12–40 字符），可点击直达官方外链。无一手信源链接严禁入选（AGENTS 8.2 红线）。

### 5.2 降级展示单元（Degraded Component）

当抓取或候选资讯四要素不全、或缺乏可验证的一手链接时，触发降级展示机制：正文摘要与外链区域完全不予渲染，外框改用深紫红暗色警示框（`#16131B` / `#991B1B`），并明确标注“⚠️ 四要素不全 · 不予展示”，向读者透明展示系统严谨风控标准。

| **INT-D01** | `01-Desktop-Dashboard` | 点击侧栏“监管与合规”或顶部导航“五类分类” | `02-Desktop-Category-Filter` | 切换至桌面分类筛选视图，自动高亮并激活“监管与合规”标签，过滤展示该分类下的全部条目与降级示例 |
