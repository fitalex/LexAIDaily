## 一、对 iandaily.xyz 的结构与排版观察

### 1.1 页面空间骨架（桌面端）

1. **画布与主面板层级**：
   - 外部画布并非纯黑或纯白，而是极淡的浅灰色冷调基底（实测为 `--color-fill: #f5f5f7`），消除纯白的高眩光；
   - 核心内容被包裹在一块整体的白色圆角大面板内（`--color-paper: #ffffff`），圆角半径约 16–20px，外围带 1px 极淡边框（`--color-line: #ebebeb`），形成轻盈的“漂浮纸张（Paper Canvas）”质感。
2. **左侧固定导航栏（Sidebar）**：
   - 宽度固定在 220–240px，自上而下布局极为克制：
     - **站名标识（Wordmark）**：手写无衬线轻量标识；
     - **极简说明**：一句话定位（如“产品设计师伊恩的每日消化”）；
     - **日期时间轴列表（Timeline List）**：当天高亮为白底圆角胶囊块（或黑底白字反转块），右侧附带当天资讯数量（如 `18`）；其余历史日期采用弱对比纯文字灰色排列，底部设“查看往期”；
     - **底部工具区**：视图切换按钮（瀑布流 / 列表）与主题切换。
3. **内容区网格节奏（3 + 1 复合列）**：
   - 主内容区采用多列等宽自适应网格（约 3 列卡片流 + 1 列“今日看点 / 综述”），列间距 20–28px；
   - 右侧第一列为“今日看点”特色栏目，顶部置入当天整体概括与导读（Summary Box），下方垂直串联普通精选卡片；其余列平铺展开当日资讯。
4. **底部居中悬浮胶囊分类栏（Floating Plaza Pills）**：
   - 固定悬浮在视口正中底部（`bottom: 24px`），采用圆角胶囊容器（`border-radius: 999px; background: #ffffff; border: 1px solid #ebebeb; box-shadow: 0 4px 16px rgba(0,0,0,0.06)`）；
   - 选项排列：`全部`（选中态为深墨色背景 `#1d1d1f` + 白字 `#ffffff`），其余分类文字均为灰色，无任何五彩斑斓的彩色药丸，视觉极其安静。

### 1.2 资讯卡片排版规律

1. **卡片质感**：
   - 纯白底色（`#ffffff`），1px 浅灰色微妙边框（`#ebebeb`），圆角 12–14px，默认无重投影；
   - 悬停（Hover）时呈现极轻微阴影与浮动反馈，右下角浮出微型外跳符号（`↗`），整体非常“薄”。
2. **文本垂直节律**：
   - **来源行**（顶部）：小号灰字（11–12px，`#86868b`），形式为 `分类 · 来源域名`；
   - **标题**（核心）：字号 16–18px，字重 SemiBold（600），深墨色（`#1d1d1f`），行距紧凑，最多 2 行；
   - **事实摘要**：字号 13–14px，常规字重（400），中灰（`#71717a`），行高 1.5–1.6，最多 3 行；
   - **无多余装饰**：卡片内部杜绝一切艳色色块、粗边框、外挂高亮框。

### 1.3 移动端布局规律

1. **单列流式结构**：宽度 100%（页边距 16px），卡片纵向单列排布。
2. **顶栏收敛**：站名与日期收纳至单行紧凑顶栏，不占屏幕纵向高度。
3. **悬浮分类栏移动适配**：底部悬浮分类胶囊支持横向滑动，右侧带渐变遮罩提示更多选项。

## 三、针对 LexAIDaily 法律情报站的取舍与改造

为将 iandaily.xyz 的“轻、干净、高密度、一眼扫读”优势与 LexAIDaily 严谨的法律情报定位完美结合，确立以下设计取舍：

### 3.1 坚持的原则（继承自参考站）

1. **白底轻卡片**：彻底废弃 PR #16 的高饱和深色发光暗调，全面转向以白、浅灰、墨黑为主的现代高可读排版。
2. **极度克制的色彩预算**：
   - 严禁红绿蓝紫五色乱飞；五大分类（监管与合规、模型与技术、判例与学术、实务与工具、行业与资本）只用中性灰阶文字区分；
   - **唯一强调色设定为：`#0969DA`（GitHub/Radix 沉稳专业蓝）**，仅在可点击外链符号（`↗`）、当前激活态指示与核心跳板按键中使用，其余全部为灰阶。
3. **空间大面板秩序**：桌面端采用“浅灰画布 + 左侧归档导航 + 纯白大面板（3+1列）+ 底部悬浮分类胶囊”的经典秩序。
4. **零 emoji**：界面中彻底剔除所有表情符号，仅使用极简线性符号（`↗`、`•`、`—`）。

### 3.2 针对法律情报站特性的适配改造（叠加的刚性约束）

1. **严格贯彻 `card-fields-v0.md`（v0.2，D-019）**：
   - 参考站为纯媒体导读，本项目为专业情报底座，必须严格落地**四要素**（核心标题、精炼摘要、实务影响锚点、原始信源链接）；
   - **列表卡片移除实务影响框**：根据 Human 裁决 D-019 与 Q1 整改，实务影响框移至详情跳板页，列表卡片回归核心三要素（来源行、标题、摘要、原始链接），层级收敛至 4 层文字样式以内，消除视觉噪音；
   - **实务影响锚点在详情页呈现**：在详情跳板页保留实务影响模块，强制标注 `[AI 初稿]` 标识；
   - **来源行集成**：顶部第一行紧凑展示为 `分类 · 事实层级 · 来源域名 · 时间`（例如 `监管与合规 · 官方发布 · example.com · 2026-11-11`），若包含未核实状态，采用深海军蓝描边微型标签 `未核实`，彻底剔除 emoji（无 `⚠️`）。
2. **杜绝编造内容（严格执行 D07）**：
   - 彻底清除未经证实的企业融资、法院具体判例或具体外部域名，禁止出现任何保留与敏感实体名称；
   - 阶段 1 草图所有内容严格采用规范的虚构占位文本（例如：`某法域人工智能生成内容标识管理办法公布`，链接采用保留域名 `example.com/...`），与 `card-fields-v0.example.json` 完全一致；
   - 顶栏与侧栏移除虚假数字统计，仅保留“今日精选（5）”“往期收录（示例）”，侧栏移除“双端协同联动引擎”产品自述，专注读者内容。
3. **Canvas UI 效果槽位预留（第五节）**：
   - 在桌面大盘主面板顶部检索与雷达标识区，静态预留 `[Canvas UI 效果槽位: Magnify/Laser 扫描镜头]`，不引入任何外部 JS 依赖或源码。

## 四、第二版视觉风格取舍与设计决策（LD-G1-02B / D-019）

### 4.1 核心视觉哲学：雾霭蓝灰 × 晨光亚麻 × 液态玻璃导航

1. **艺术底色与晕染色斑**：
   - 底色采用温暖微黄的传统渐变（`#A0BCCE` 至 `#EAE1D3`），消除纯冷灰界面的疏离感，赋予法律资讯深厚、沉稳的学术与文献底蕴；
   - 在页面底层铺设 2–3 团极淡的水墨晕染色斑（墨青 `#2A3A40`、淡赭 `#7C5238`，不透明度严格控制在 10%–12%），其核心功能是为悬浮其上的液态玻璃导航提供丰富而克制的物理折射背景。
2. **卡片实色约束（D-019 Human 决策）**：
   - 放弃“全站玻璃化”，坚决贯彻“内容实色、导航透光”。
   - 资讯卡片一律采用实色暖白面板（`#FFFDF8`），搭配 1px 细线暖灰描边（`#E6DFC8`）与微弱柔和投影；
   - **对比度与可读性保障**：实色卡片背景 `#FFFDF8` 与墨黑正文 `#1F1B16` 的对比度高达 `16.84:1`，远超 WCAG AAA 级标准的 `7:1`，确保长段法律事实摘要在 3 分钟内清晰可扫读，杜绝文字背景杂乱导致的视觉疲劳。
3. **液态玻璃（Liquid Glass）材质取舍与边界**：
   - **适用边界**：全站严格仅在两处使用玻璃材质：(1) 底部悬浮分类切换条；(2) 侧边栏/顶栏日期导航列表。其余一律实色；
   - **材质物理属性**：模拟半透明厚质玻璃（Penpot 中采用 60% 暖白填充 `#FFFFFF`，1px 渐变描边顶部白高光 `#FFFFFF` 70%、底部弱灰 `#DCD4C0` 50%，柔和偏暖扩散阴影 `0 8px 32px rgba(31, 27, 22, 0.08)`）；
   - **滑块交互形态**：分类栏与日期栏的激活选中态均为“高亮玻璃滑块（Luminous Glass Slider）”，通过提升透明度与高光反射表达选中，而非粗暴的实心色块；
   - **Apple 设计语言取舍**：仅借鉴现代系统级 UI 中“透光玻璃漂浮于内容层之上”的空间层级与折射光学逻辑，**不使用 Apple 任何专有图标、SF 字体、素材或商标**；
   - **无障碍保障**：提供 `reduced-transparency` 令牌组，在不支持模糊滤镜或开启减弱动态/透明度的设备上自动回退为 `#F6F1E6` 实色边框胶囊。

### 4.2 三套中文字体分工与排版层级

根据 D-019 与任务书第 3.2 节要求，确立“三套字体各司其职”的字形系统：

| 字体名称 | 字形大类 | 许可证 | 页面职责 | 视觉意图与字号规范 |
|---|---|---|---|---|
| **霞鹜文楷** (LXGW WenKai TC) | 楷体 / 书写体 | SIL OFL-1.1 | 卡片标题、详情页大标题 | 核心视觉特征，书卷气与人文质感，打破常规后台刻板感。L 卡标题 30px、M 卡标题 21px、S 卡标题 18px。 |
| **思源宋体** (Noto Serif SC) | 宋体 / 衬线体 | SIL OFL-1.1 | 站名标识 (Wordmark) | 庄重、权威的法律出版物气质，字重 Bold (700)，字号 30px，与楷体标题形成优雅互补。 |
| **思源黑体** (Noto Sans SC) | 黑体 / 无衬线 | SIL OFL-1.1 | 摘要正文、来源行、日期、分类标签、数字 | 严谨高识别度，保证事实密集型长文的可读性。摘要 $\ge 14.5\text{px}$（设定为 15px/26px 行距），来源小字 12.5px。 |

### 4.3 唯一强调色：深海军蓝（Deep Navy Blue `#14284B`）

- 彻底收敛色彩预算，全站仅保留一个强调色：`#14284B`（沉稳、深邃的司法与行政墨蓝）；
- 作用范围：
  1. “头条”标记：深海军蓝实底白字微型标签（高对比徽章）；
  2. “未核实”标识：深海军蓝 1px 细线描边微型标签；
  3. 链接与交互态：默认墨黑带细下划线，悬停时触发深海军蓝变色；
  4. 分类激活文字：深海军蓝加粗字。
- 绝不与红、绿、黄、紫混用，保持专业情报站的沉静力量。
