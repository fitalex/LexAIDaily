## 一、四要素与五类标签（原文转写）

`ROADMAP.md` Gate 1“核心任务 2”原文（逐字引用）：

> 设计标准资讯单元结构（“核心标题 + 精炼摘要 + 实务影响锚点 + 原始信源链接”）及五大分类标签体系（模型与技术、实务与工具、监管与合规、判例与学术、行业与资本）。

本 v0.3 只使用上述名称与顺序：

1. **四要素**：核心标题、精炼摘要、实务影响锚点、原始信源链接。
2. **五类标签**：模型与技术、实务与工具、监管与合规、判例与学术、行业与资本。

不新增、不改名、不合并、不拆分五类标签。`README.md` 第 3 节把标准单元简写为“核心标题 + 精炼摘要 + 实务影响 + 原始链接”；本表按 D01 以 ROADMAP 全称为准，简称不另立字段（差异处理见第十节第 3 条；README 为冻结基线，本任务不改）。

v0.3 延续并深化**展示层级**：四要素仍是标准单元的完整定义，Web 列表卡片为极简报刊摘录视图，点击卡片弹出的详情跳板页为四要素全展开视图（见第二节）。

## 二、展示层级（D-019 + D-027）

同一份内容按展示位置分两层，各层展示字段是四要素的子集加状态位与视觉插画位。

### 2.1 Web 列表卡片（首屏流动横轨、三栏大盘、分类筛选列表）

- 字段：`16:7` 主题插画（依 `design/illustration-spec.md` v2.0）+ 核心标题 + 朱红微标（重要度“头条” / 分类标签 / “未核实”状态位）+ 3 行内精炼摘要 + 占位标记（演示态显示小号“示例”）。
- **不展示「实务影响锚点」**（D-019）与**不展示「原始信源链接 / 来源域名（含 `example.com` 外链）」**（D-027）：列表卡片只承担 3 分钟极速报刊扫读与点击入口，减少外链与长文本噪声。
- 本表只定语义与长度档位，具体纸底色、字号与 1px 黑线规范见 `design/design-system.md`（v3.0）。

### 2.2 详情跳板弹窗（点击任意列表卡片弹出）

- 字段：列表卡片的全部核心信息，补齐**完整摘要**、**实务影响锚点**（带「AI 初稿」标识）、**原始信源链接（含来源域名与直达按钮）**、**事实层级**、**日期**、**分类标签**与**「插画由 AI 生成」标注**（D-014）。
- 详情跳板弹窗是四要素齐全的位置，不再设置二次点击才能看到的内容。
- 实务影响锚点的“AI 初稿”标识规则不变：Human 确认前必须标注（`AGENTS.md` 10.8），见第六节 6.1。

## 三、字段总表

| 字段（显示名） | 展示层级 | 用途 | 必填/可选 | 排版用长度参考 | Web 与公众号两端的差异 | 缺失时的降级显示 |
|---|---|---|---|---|---|---|
| 主题插画（v2.0） | 两者（Web 卡片 + 详情弹窗） | 16:7 直角黑框视觉锚点，按分类锁色系、按标题隐喻配图（D-027） | 可选（原型与正式 Web 建议配备） | 21:9 生成、16:7 裁切，WebP ≤ 120 KB | Web 列表与详情均展示，详情附「插画由 AI 生成」说明（D-014）；公众号按 LD-G1-03 裁切或省略 | 加载失败时平滑回退内置 SVG 占位或按分类基准图补位 |
| 核心标题 | 两者 | 一眼判断这条资讯讲什么，是卡片主信息 | 必填 | 18–32 个汉字为宜，硬上限 40；桌面/移动最多 2 行 | Web 报刊粗衬线大标题；公众号最多 2 行、超长省略，完整标题在 Web 保留 | 不用摘要或链接代标题；该卡片不展示并标待补 |
| 精炼摘要 | 两者 | 2–3 句说清事实，区分事实与观点 | 必填 | 分短/常规/长三档，见第五节；上限 160 字 | Web 列表卡片截断至 3 行，详情弹窗全文展开；公众号放宽行高、最多 4 行 | 不渲染摘要区，不用标题与锚点拼接代替；该卡片不展示并标待补 |
| 实务影响锚点 | **仅详情跳板弹窗**（列表卡片不展示，D-019 / D-027） | 给法律从业者的实务影响提示；Human 确认前必须带“AI 初稿” | 必填 | 30–60 个汉字为宜，上限 80；2–3 行 | Web 详情弹窗内以虚线黑框 + 左侧粗黑条展示；公众号是否包含待 Human 于 LD-G1-03 前确认 | 不渲染锚点区，不写“无影响”等推断；详情页四要素不全时该条不展示并标待补 |
| 原始信源链接 | **Web 仅详情跳板弹窗**（D-027）；公众号经“阅读原文”跳转 | 读者回看一手来源，落实来源透明 | 必填 | 显示文本 12–40 个字符（域名 + 短标识）；完整 URL 不在列表卡片展示 | Web 列表卡片隐藏，点击卡片后在详情弹窗点击直达按钮（新标签打开）；公众号展示来源文本并经“阅读原文”→ Web 详情页 | 不渲染外链；该条不入选（AGENTS 8.2：无一手信源链接不入选） |
| 分类标签 | 两者 | 五类之一，供分类筛选与扫读定位 | 必填（单标签，五类取一；D-016） | 固定 2–4 个汉字，单行不截断 | Web 列表以朱红微标或索引条筛选呈现，详情顶栏完整展示；公众号用内联标签 | 不显示标签，不默认归入任何一类；该卡片不展示并标待补 |
| 重要度 | 列表卡片 | 标识当日核心头条（微标优先显示“头条”） | 可选（缺省“常规”；Human 终审勾选） | 固定两值“头条”“常规”，不截断 | 两端取值与语义相同；Web 端头条优先置入首屏流动横轨首张 | 缺省按“常规”渲染，不推断为“头条”；AI 不得自行标“头条” |
| 日期 | 详情跳板弹窗 + 报眉期号栏 | 让读者判断资讯时效 | 必填（真实资讯；占位示例从略，见第九节） | 显示到日（YYYY-MM-DD 形式）；单行 | Web 报眉展示当期日期，详情顶栏展示单条日期；公众号同 | 真实资讯缺失时该卡片不展示并标待补；占位示例不写日期，不按“待补”处理 |
| 来源域名 | **Web 仅详情跳板弹窗**（D-027） | 便于在详情跳板页直达前确认信源主体 | 必填 | 域名主体（12–40 字符），单行、超长省略 | Web 列表卡片隐藏，详情弹窗直达按钮内展示域名；公众号显示纯文本 | 不渲染；原始信源链接缺失时一并标待补 |
| AI 初稿标识 | 两者（逐字段） | 标明对应字段内容为 AI 生成、尚未经 Human 确认 | 条件显示（状态位） | 固定文案“AI 初稿”，不截断；字号不高于正文字号 | Web 首屏「今日综述」与详情「实务影响」固定带虚线角标；公众号行内文字不可省略 | 字段来源未确认时默认显示（保守）；仅 Human 确认后移除 |
| 未核实标识 | 两者 | 提示发布机构、日期、版本或效力状态无法核实 | 条件显示（状态位） | 固定文案“未核实”，不截断 | Web 列表以朱红描边微标呈现；公众号行内文字 + 文末说明句（禁用 emoji） | 未提供核验结果时默认显示（保守）；不得推断“已核实” |
| 事实层级（Human 已采纳三档；D-016） | 详情跳板弹窗（Web）；公众号行内 | 区分已证实事实 / 官方数据 / 市场观点 | 条件显示（状态位） | 固定三选一：“已证实事实”（5 字）、“官方数据”（4 字）、“市场观点”（4 字）；单行 | Web 详情顶栏与引用格式中展示；公众号行内“事实层级：…”文字 | 不显示，不默认归入任何层级；不推断 |
| 占位标记 | 列表卡片与详情顶栏（演示态） | 标明这是虚构占位内容，不是真实资讯 | 条件显示（状态位；见第七节） | 小号“示例”标识，固定 2 字 | Web 标题旁小号细框“示例”；真实样本 `placeholder: false` 时隐藏 | 无标记即视为真实样本；示例文件必须为 `true` |

## 四、重要度（显示字段）

- 取值只有两个：**头条**、**常规**。缺省为“常规”，**由 Human 终审时勾选**，AI 不得自行标“头条”（D-019）。
- 作用：决定头条微标展示及首屏流动横轨的优先排序位置。

## 五、摘要长度档位

| 档位 | 字数建议 | 排版含义 |
|---|---|---|
| 短摘要 | **少于 60 字** | 一句话事实型资讯；**不作缺陷处理**，仍必填，不因过短退回 |
| 常规摘要 | **60–120 字** | 默认档，适配列表卡片 3 行展示 |
| 长摘要 | **121–160 字** | 上限 160；Web 列表卡片按 3 行截断，点击详情弹窗全文展开 |

## 六、三个状态显示位

- **6.1 “AI 初稿”**：依据 `AGENTS.md` 10.8，AI 生成的今日综述、摘要与实务影响锚点在 Human 确认前一律标注“AI 初稿”，仅 Human 确认后移除。
- **6.2 “未核实”**：依据 `AGENTS.md` 8.2 红线，无法核实发布机构、日期、版本或效力状态的条目须标“未核实”（朱红描边，严禁 emoji）。
- **6.3 事实层级（D-016）**：三档为 **已证实事实 / 官方数据 / 市场观点**；Web 端置于详情跳板弹窗顶栏与引用格式中，保持条件显示。

## 七、占位标记

- 占位示例不再把“【示例占位】”写进标题（D-019），改为字段 `placeholder: true` 并在列表卡片与详情顶栏显示小号“示例”标识；真实样本为 `false` 时隐藏。

## 八、跨端显示规则

- **Web 列表卡片**：`16:7` 直角黑框插画 → 核心标题 + 朱红微标 + 占位标记（演示态）→ 3 行内精炼摘要；**严禁展示来源外链（`example.com`）与实务影响锚点**（D-027）。
- **Web 详情跳板弹窗**：顶栏元数据（分类 · 事实层级 · 日期 · 占位标记）→ 16:7 插画与「插画由 AI 生成」图注 → 核心标题 → 完整摘要 → 实务影响锚点（带「AI 初稿」）→ 一手信源直达按钮（含来源域名）与法律人引用复制按钮。
- **公众号**：样式全部内联，不依赖 hover，跳转经“阅读原文”→ Web 详情页，具体模板由 LD-G1-03 验证。
