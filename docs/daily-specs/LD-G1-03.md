## 一、背景与目标

做出能粘贴进微信公众号后台的“每日固定栏目”排版模板，样式全部写在标签上（内联）。做完之后，Human 能拿一份真实样本生成的 HTML 粘贴进后台草稿，在 iOS 与 Android 上预览。

## 二、范围

- **输入**：`ROADMAP.md` Gate 1；`design/card-fields-v0.md`；`design/design-system.md` 与令牌（LD-G1-02）；LD-G1-04 样本集。
- **输出**：
  1. `design/wechat/template.html`：栏目模板（样式写在源文件的 CSS 中，由脚本内联）。
  2. `scripts/wechat-prototype/build.mjs`：用 juice 把样式内联并生成成品 HTML 的原型脚本。
  3. `design/wechat/samples/`：用样本集生成的成品 HTML。
  4. `design/wechat/README.md`：用法，以及已知被后台剥离或不支持的写法（须有实测依据，没有就写“未实测”）。
  5. `design/wechat/read-original-flow.md`：“阅读原文”跳转 Web 详情页的联动动线设计。
  6. `design/wechat/DEVICE_TEST.md`：真机预览记录模板（Human 填写）。
  7. `package.json`、锁文件：只含 juice。
  8. `THIRD_PARTY_NOTICES.md`：在 LD-G1-02 创建的基础上追加。
- **可改文件**（`design/`、`scripts/` 默认归 Codex，D-011 期间本任务书授权 DeepSeek Harness 修改）：`design/wechat/`、`scripts/wechat-prototype/`、`package.json`、锁文件、`THIRD_PARTY_NOTICES.md`。
- **不可改文件**：`README.md`、`ROADMAP.md`、`AGENTS.md`、`docs/` 全部、`design/card-fields-v0*`、LD-G1-02 的设计文件（需改令牌请回 Claude）。
- **非范围**：本脚本只做原型生成，**不是 Gate 2 的“一键渲染导出脚本”**，不得扩展成采集、发布或定时流程；不登录公众号后台；不接触后台凭据；不选域名（动线里的网址用保留域名占位，如 `https://lexaidaily.example/d/2026-11-07`）；不实现外链跳转（Gate 3）。
- **复用与参考（D-008）**：
  - 依赖：[Automattic/juice](https://github.com/Automattic/juice)（MIT），仅用于内联样式；安装用 `npm install --ignore-scripts`，版本固定。
  - 可参考或合规拷贝：[doocs/md](https://github.com/doocs/md)（WTFPL）的主题到内联样式的处理思路，主要在 `packages/core/src/theme`。如拷贝，只取最小必要文件，不带入其依赖、logo、图片和 CDN 链接，并按 D-008 登记。
  - 它是通用 Markdown 编辑器，我们要的是固定栏目模板，不整体搬入。

## 五、验证与证据要求

- 必须运行：
  - `npm install --ignore-scripts`、`npm ls`、`npm audit`（如实粘贴输出；网络受限未能运行要写明）
  - `node scripts/wechat-prototype/build.mjs --in <样本 JSON> --out /tmp/a.html` 运行两次并比较 `sha256sum`
  - `grep -c -E "<style|class=|<script" design/wechat/samples/*.html`（应全为 0）
  - `git diff --name-only origin/main...HEAD`（必须全部落在“可改文件”内）
- 微信后台的实际渲染效果只有 Human 能验证，DeepSeek Harness 不得写“微信兼容”之类结论，只能写“待真机预览”。CI 未配置，写“CI 未触发”。
