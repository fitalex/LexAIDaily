## 一、背景与目标

Gate 1 的 Web 原型和公众号排版都要用同一套“资讯卡片”结构。本任务把这套结构写成一份字段表，让设计与排版两个任务有同一个依据。做完之后，LD-G1-02 与 LD-G1-03 不必各自猜字段。

## 二、范围

- **输入**：`ROADMAP.md` Gate 1 核心任务 2；`README.md` 的五类分类标签与编辑原则；`AGENTS.md` 8.2 红线与 10.8（“AI 初稿”标注）；D-005（Gate 1 只定义 UI 展示字段，正式采集数据契约归 Gate 2）。
- **输出**：
  1. `design/card-fields-v0.md`：字段表与显示规则。
  2. `design/card-fields-v0.example.json`：不少于 3 条示例，覆盖不少于 3 个不同分类。
  3. `design/README.md`：目录说明（只写目录用途与文件清单，不写项目定位）。
- **可改文件**：上述 3 个文件。
- **不可改文件**：`README.md`、`ROADMAP.md`、`AGENTS.md`、`CLAUDE.md`、`docs/` 全部。
- **非范围**：不定义采集数据契约、数据库结构或 API；不选技术栈；不做视觉设计；不新增依赖或配置文件；不添加许可证。
- **参考（只读，不拷贝）**：[LearnPrompt/ai-news-radar](https://github.com/LearnPrompt/ai-news-radar)（MIT）的每日页面条目结构。如确需拷贝其中任何文字或结构，按 D-008 登记后再用。

## 三、冻结边界

README 定位与路线图、ROADMAP 的验收标准、编辑原则、AGENTS.md。字段表只能转写这些文件已有的要素，不得新增或改写五类标签。
