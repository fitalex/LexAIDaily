## 一、背景与目标

设计与排版成果会陆续进入 `design/`。本任务把它们整理成一份人能顺着读的索引，并核对各处引用和第三方登记表有没有漏。做完之后，Human 做验收时不用自己找文件。

## 二、范围

- **输入**：已合并的 `design/`、`THIRD_PARTY_NOTICES.md`、`docs/daily-specs/`、`docs/coordination/STATUS.md`。
- **输出**：`docs/gate1-design-index.md`，包含：
  1. `design/` 下每个已合并文件的一句话用途与链接；
  2. Penpot 链接与文件版本（只引用 `design/penpot.md` 的内容，不自行补充）；
  3. 令牌文件与样稿的位置；
  4. 第三方登记表入口，以及“登记表条目字段是否齐全”的核对结果。
- **可改文件**：`docs/gate1-design-index.md`；`docs/daily-specs/README.md` 中各任务的 PR 链接列（只补链接，不改其他列）。
- **不可改文件**：`design/`、`scripts/`、`tests/`、`THIRD_PARTY_NOTICES.md`、`README.md`、`ROADMAP.md`、`AGENTS.md`、`docs/coordination/`。
- **非范围**：不改设计与排版内容；不判断许可证是否合规（只核对字段齐全）；不写代码与设计稿；不评价视觉。发现问题写进 PR 描述，由对应 Owner 或 Claude 处理。

## 三、冻结边界
