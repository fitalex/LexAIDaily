# LexAIDaily

> **专注法律 AI 领域的每日精选资讯站与公众号情报引擎**  
> **当前阶段：** Gate 0｜项目文档与产品规划（待正式验收）

---

## 1. 项目介绍

在生成式 AI 与法律科技（LegalTech）高速演进的当下，行业动态呈现高度碎片化与高噪音特征。**LexAIDaily** 致力于构建一个高信噪比、强实务导向的法律 AI 每日精选资讯网站；同时，本项目亦作为**微信公众号运营的核心信息采集雷达、深度选题素材库与每日固定内容栏目生成引擎**。

### 核心使命
充当法律科技领域的全天候“信息雷达”，过滤市场噪音，连接前沿 AI 技术与严肃法律实务；既为公众提供信源可溯的每日情报，也为自媒体内容运营提供持续、结构化的高质量弹药。

### 产品定位
以“专业精选、可信来源、高效阅读”为核心价值，集**独立 Web 情报底座、微信公众号每日固定栏目与深度选题引擎**于一体的法律 AI 资讯中枢。

### 目标用户
* **执业律师：** 追踪 AI 辅助办案工具实效、检索系统迭代及律所数智化提效方案。
* **企业法务：** 监控全球 AI 立法监管、数据合规边界、合同自动化审查与风控实践。
* **法律研究者：** 捕获法律大模型评测基准、前沿学术论文、司法伦理探讨与典型判例。
* **LegalTech 从业者与内容运营者：** 洞察全球产品动态与商业化路径，高效获取每日行业快讯与深度长文选题。

## 2. 核心功能规划

*注：当前项目处于 Gate 0 规划阶段，以下功能模块将在后续研发周期中分步实现。*

* **每日资讯精选与价值研判（Daily Curation & Impact）：** 按日输出固定体量的高价值情报卡片，在提炼核心事实的基础上标注“实务影响锚点”，辅助读者快速完成价值判断。
* **全网信息采集与选题素材库（Radar & Topic Pool）：** 自动化监测全球法律 AI 动态，在对日常快讯进行归类的同时，自动识别高热度、高争议议题并沉淀至“公众号深度选题池”。
* **公众号固定栏目生成与双端协同（WeChat Column Engine）：** 支持将每日精选资讯一键渲染为适配微信公众号排版的固定栏目图文，并通过公众号“阅读原文”与 Web 端详情页联动，破解微信生态外链跳转限制。
* **多维分类与原始来源追溯（Categorization & Traceability）：** 支持按“模型与技术”、“实务与工具”、“监管与合规”、“判例与学术”、“行业与资本”分类筛选；每条资讯强制保留一手信源链接，支持在 Web 端一键跳转查验。
* **历史归档与知识库检索（Archive & Retrieval）：** 按时间轴与核心标签沉淀每日动态，弥补微信公众号历史内容检索不便的短板，构建可跨期回溯的法律 AI 知识库。

## 3. 设计理念

**LexAIDaily** 追求“精密雷达工具感”与“跨端极速阅读流”的有机结合：

* **视觉与交互基础（受 Canvas UI 启发）：** 在 Web 端引入画布式的空间秩序感与克制的组件语言，通过清晰的网格布局、微妙的边框层级与高对比度现代排版，构建高公信力的情报大盘；并将这套秩序感映射为微信公众号固定栏目的标准化排版视觉。
* **内容策展与阅读体验（借鉴 Ian’s Daily 模式）：** 采用高密度的轻量级日报策展结构，将复杂动态封装为“核心标题 + 精炼摘要 + 实务影响 + 原始链接”的标准单元，确保读者无论在网页端还是公众号栏目中，均可在 3 分钟内完成沉浸式扫读。

## 4. 编辑原则

为兼顾情报雷达的采集效率、公众号栏目的可读性与法律行业的严谨性，项目确立以下四项准则：

1. **信息真实性：** 严格区分“已证实的客观事实”、“官方发布数据”与“市场观点评论”，剔除过度包装的公关软文与标题党。
2. **来源透明：** 建立高权重信源白名单，优先采集立法与监管机构、法院公开文书、顶会论文、官方技术博客及权威科技媒体，所有条目强制标注一手或核心信源。
3. **法律专业性：** 从法律实务适用性、合规风险、证据效力及技术边界等专业视角提炼摘要与栏目锐评，拒绝泛科技新闻的简单搬运。
4. **自动化监测与人工把关（Human-in-the-Loop）：** 采用“自动化雷达采集 + 运营者精选终审”的协同机制。AI 管线负责多语种全天候抓取、分类与初稿生成，运营者负责价值勾选、实务点评注入与双端发布终审。

## 5. 项目路线图

项目采用门径管理（Stage-Gate）模式推进，划分为五个关键阶段，各阶段严格串行准入：前一阶段未通过正式验收，不得进入下一阶段实质研发。各阶段的核心任务、交付成果与验收标准见 [ROADMAP.md](ROADMAP.md)。

- [ ] **Gate 0｜项目文档与产品规划（当前阶段，待正式验收）：** 对齐“独立 Web 情报底座 + 微信公众号每日固定栏目与深度选题引擎”的产品定义、目标用户与编辑准则；完成 README、ROADMAP 与多 Agent 协作规范（AGENTS.md）入库。
- [ ] **Gate 1｜Web UI 与公众号排版原型：** 建立统一设计系统，完成 Web 桌面端与移动端核心视图高保真原型，以及适配微信公众号编辑器的每日固定栏目内联排版模板。
- [ ] **Gate 2｜法律 AI 信息采集与内容工作流：** 建立全球法律 AI 信源白名单、自动化采集与选题分级管线、AI 摘要与实务影响锚点初稿工作流、人工审校 SOP 及公众号一键导出脚本。
- [ ] **Gate 3｜MVP 开发与双端上线：** 完成 Web 站点开发、历史归档与外链跳板功能，正式跑通“雷达采集 → 人工终审 → 网站更新 → 公众号固定栏目日更”的完整链路。
- [ ] **Gate 4｜用户增长与商业模式验证：** 依托公众号固定栏目与 Web 知识库沉淀精准读者，建设私域社群，并围绕深度行业内参、品牌合作与专业服务验证商业闭环。
